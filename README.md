# Stanbic IBTC Bank — Credit Risk Intelligence Platform

**Course:** BAN6800 — Business Analytics Capstone  
**Module:** 2 of 5  
**Problem:** Credit Risk Assessment & Loan Default Prediction  
**Dataset:** Home Credit Default Risk (Kaggle, 2018) — 307,511 records  

## Project Structure
- data/ — raw, processed, external datasets (DVC-tracked)
- notebooks/ — EDA, preprocessing, modelling, explainability
- src/ — data ingestion, features, models, visualisation scripts
- models/ — saved model artifacts
- reports/ — figures and stakeholder deliverables
- tests/ — unit and integration tests
